## ✨ Overview

This repository contains the full frontend landing experience for Q-RETIX AI, including:

- 🦸 **Immersive hero** — marketing experience with motion and animated layouts
- 📰 **Blog & research hub** — dynamic content previews with category filters
- 🧬 **Product & solution showcases** — pharmaceutical intelligence sections
- 📬 **Waitlist & community CTAs** — lead capture and customer engagement
- 📄 **Full site pages** — Legal, Support, Press, Careers & Documentation

The site is designed with a **premium, data-driven brand voice** and is optimized for modern web deployment.

---

## 🎯 Key Features

- **Next.js 16 App Router** — server-rendered routes and fast page loads
- **React 19** — client components for interactive sections
- **Tailwind CSS v4** — responsive, utility-first styling
- **Framer Motion** — smooth page transitions and hero interactions
- **Dynamic blog routes** — `src/app/blog/[slug]/page.tsx`
- **Prisma** — type-safe data layer ready for backend integration
- **Custom sections** — research timeline, feature cards, blog showcase & waitlist community
- **Fully responsive** — mobile-first navigation and adaptive layout

## 🚀 Quick Start

**Prerequisites:** Node.js 18+

```bash
# 1. Clone the repository
git clone https://github.com/Ahsan-Dogar/Q-RETIX-AI.git
cd Q-RETIX-AI

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env   # (if applicable)

# 4. Run the dev server
npm run dev
```

Open **http://localhost:3000**.
